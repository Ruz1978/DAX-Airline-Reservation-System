# ✈️ DAX Airline Reservation System

A Java-based console application that simulates an airline reservation system. The project provides a menu-driven system for managing flights, passengers, reservations, cancellations, and flight scheduling.

## 📌 Overview

The **DAX Airline Reservation System** is designed to demonstrate the practical use of Java and Object-Oriented Programming concepts through a real-world airline reservation scenario.

Users can interact with the system through a console-based menu to perform different airline-related operations.

## ✨ Features

- ✈️ Flight scheduling
- 👤 Passenger registration
- 🎫 Flight reservation
- ❌ Reservation cancellation
- 💺 Seat management
- 🔎 Flight information
- 👥 Passenger management
- 🔐 Admin and passenger roles
- 🆔 Automatic ID generation
- 📋 Display passenger and flight information
- 🛫 Flight distance calculation
- ⏱️ Flight travel-time calculation

## ▶️ How to Run

### Using Eclipse

1. Clone this repository.
2. Open **Eclipse IDE**.
3. Select **File → Import**.
4. Choose **Existing Projects into Workspace**.
5. Select the cloned project folder.
6. Open the `src` folder.
7. Open `User.java`.
8. Run `User.java` as a **Java Application**.
9. Follow the instructions displayed in the console.

### Using Git Bash / Command Line

Navigate to the `src` directory:

```bash
cd src
```

Compile the Java files:

```bash
javac *.java
```

Run the application:

```bash
java User
```
