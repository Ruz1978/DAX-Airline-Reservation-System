DAX AIRLINE RESERVATION SYSTEM
================================

Eclipse-ready Java project.

Main class:
    User.java

Requirements:
    Java 17 or newer (the project uses Java text blocks).

How to import into Eclipse:
1. Extract this ZIP if Eclipse does not recognize the archive directly.
2. In Eclipse: File -> Import.
3. General -> Existing Projects into Workspace.
4. Choose the extracted folder (or Select archive file if Eclipse detects the project).
5. Select "DAX Airline Reservation System".
6. Click Finish.
7. In Package Explorer, open src -> User.java.
8. Right-click User.java -> Run As -> Java Application.

Default admin login:
    Username: root
    Password: root

The original reservation, passenger, admin, flight scheduling,
booking and cancellation functionality has been preserved.
The airline branding has been changed to DAX Airlines.
